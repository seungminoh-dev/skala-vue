### 이 문서는 API Refresh Rule을 정의합니다

-- 저장소는 localStorage만 사용하며, 날씨 데이터 전체 항목을 직렬화하여 저장하고 JSON으로 꺼내옵니다.
-- localStorage가 JSON저장을 지원하면, JSON째로 저장합니다(날씨 배열)

## 자동으로 Refresh 될 때

1. 사이트에 접속할 떄 (새로고침 포함): 명시적인 사이트 접근, 새로고침이 발생 했을 때 아래의 #Refresh Rule#을 시행합니다.
2. 도시를 추가할 때 -> 해당 항목만 데이터를 새로 받아와서 추가합니다.

# Refresh Rule

1. 현재 등록된 날씨 위치 항목을 스캔합니다.
2. 업데이트 된 지 "2시간" 지난 항목을 자동으로 업데이트 합니다.
3. 별도의 오류는 추적하지 않습니다. 업데이트에 실패했으면 Console에만 왜 실패했는지 표기하고, 재시도 하지 않습니다.

# 전체 Refresh -> 수동

상단 메뉴에 Refresh Icon(Button)을 추가하고, 위 버튼을 클릭하면 전체 날씨 데이터를 업데이트 합니다. 상단 Toast로(아마 이 이름이 맞는지는 모름)으로
성공/실패 결과만 표기합니다.

# 대부분의 오류는 추적하지 않는 것으로 변경하고, 기존에 사용하던 api재요청 시스템, 프리셋 자동 매칭 시스템, 지역 위/경도가 비슷하면 reject하는

# api call 절약 로직은 사용하지 않고 추후 개선사항으로 두겠습니다.
