## 4. Essential 상태

```text
카드 클릭       → selectedCityInfo 변경 → 상태바·watch 로그
상세 버튼       → @click.stop → /weather/:id
검색 입력       → :value + @input → searchQuery → watchEffect 로그
빈 검색어       → 전체 weatherList
검색 결과 없음  → ElEmpty 안내
온도 ≥ 25       → v-if 더움 라벨
온도 < 25       → v-else 선선함 라벨
단위 변경       → configStore.unit → 메인·상세 동시 변경
```
